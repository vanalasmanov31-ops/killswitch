Как это работает
1. Залей status.json в репозиторий GitHub.
2. В расширении укажи raw-URL этого файла (или замени YOUR_USER/YOUR_REPO в panel.js).
3. Здесь жми кнопку — скачается готовый JSON. Замени им файл в репо (Commit) — и у всех Instant/Studio отключатся в течение ~30 сек.
Без токена запись в GitHub из браузера невозможна: один клик = скачать JSON → Commit на GitHub (2 клика суммарно).
